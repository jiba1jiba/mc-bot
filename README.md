# Discord-бот: таблист + твинки на Minecraft-сервере

Бот живёт на VPS/домашнем мини-ПК и работает, даже когда ваш ПК выключен.
Через Discord можно смотреть, кто онлайн на сервере, и запускать/выключать
аккаунты-боты (скрыто`, …).

Целевой сервер по умолчанию: **серв`** (Purpur 26.1.2, `online-mode=false`).

---

## Что умеет

| Команда | Что делает |
| --- | --- |
| `/list` | Таблист: кто сейчас онлайн, онлайн/слоты, версия, кнопка «Обновить» |
| `/join <ник>` | Запустить бота под указанным ником (ник автоматически сохраняется) |
| `/joinall` | Запустить все сохранённые аккаунты |
| `/leave <ник>` | Выключить одного бота |
| `/leaveall` | Выключить всех |
| `/accounts` | Список сохранённых ников и их статус |
| `/add <ник>` | Добавить ник в список |
| `/remove <ник>` | Удалить ник из списка (и выключить, если запущен) |
| `/status` | Статус, аптайм, попытки переподключения, ошибки |

Дополнительно:

- **Авто-реконнект** при обрыве/кике (с растущей задержкой).
- **Умная остановка**: кик по вайтлисту/бану не вызывает бесконечные попытки.
- **Автоопределение версии** Minecraft по ответу сервера (`MC_VERSION=auto`).
- **Ответ на ресурспак**: сервер держит вход, пока клиент не подтвердит пак —
  бот подтверждает его автоматически (иначе зависает на «подключение»).
- **AUTO_JOIN** — после перезагрузки VPS боты поднимаются сами.
- Таблист берётся из tab-листа подключённого бота (полный список), а если ботов
  нет — через ping сервера (сэмпл + онлайн).

## Важно про этот сервер

На 'сервер` **включён вайтлист**. При входе под ником, которого нет
в вайтлисте, сервер отвечает:

> Ты не в вайтлисте! Подай заявку на сервер в TG TineWix_Support_bot

То есть:

- `/add` и `/join` могут добавить **любой** ник, но зайти получится только под
  ником, который **уже добавлен в вайтлист сервера**.
- Если нужен новый твинк — сначала добавьте его в вайтлист (через админку/ТГ
  сервера), потом `/join`.
- Не запускайте ник, под которым уже сидите с обычного клиента: сервер выкинет
  одного из двух.
- На сервере 20 слотов.
- Некоторые серверы ограничивают число аккаунтов с одного IP — если часть ботов
  выкидывает, уменьшите их количество или разместите на разных IP.

## Требования

- **Node.js 22+**
- Созданное приложение Discord и токен бота
- Аккаунт Discord с правом «Управление сервером» (или роль/юзер из `.env`)

## Быстрый старт (Windows)

Самый простой способ — двойной клик по **`start.bat`**: он создаст `.env`,
откроет блокнот для токена и поставит зависимости.

Вручную:

```powershell
cd C:\Users\misha\Documents\mc-bot
npm install
copy .env.example .env
notepad .env
npm start
```

Если PowerShell ругается на `npm.ps1` («выполнение сценариев отключено»),
используйте:

```powershell
cmd /c npm install
cmd /c npm start
```

Либо разрешите скрипты один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

После запуска в консоли должно появиться `Discord: вошёл как ...`.
В Discord появится команда `/list`.

### 1. Создать Discord-бота

1. Откройте <https://discord.com/developers/applications> → **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопируйте токен в `DISCORD_TOKEN`.
3. **Никакие Privileged Intents не нужны** (боту хватает `Guilds`).
4. Пригласите бота на свой сервер по ссылке (подставьте свой `client_id`):

   ```
   https://discord.com/oauth2/authorize?client_id=ВАШ_CLIENT_ID&permissions=18432&scope=bot%20applications.commands
   ```

   `18432` = Send Messages + Embed Links. Scope `applications.commands`
   обязателен для слеш-команд.

### 2. Узнать ID сервера

Включите **Настройки → Расширенные → Режим разработчика**, затем ПКМ по
своему Discord-серверу → **Копировать ID сервера** → в `DISCORD_GUILD_ID`.
С указанным ID команды появляются сразу; без него — глобально (до 1 часа).

### 3. Заполнить `.env`

Минимум:

```env
DISCORD_TOKEN=ваш_токен
DISCORD_GUILD_ID=ваш_сервер_id
```

Остальное уже настроено под сервер. Полный список — в `.env.example`.

## Конфигурация (`.env`)

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `DISCORD_TOKEN` | — | Токен бота (обязательно) |
| `DISCORD_GUILD_ID` | — | ID сервера для быстрой регистрации команд |
| `ADMIN_ROLE_ID` | — | Роль, которой разрешены команды |
| `ADMIN_USER_IDS` | — | ID пользователей через запятую |
| `ALLOW_EVERYONE` | `false` | `true` — команды всем участникам |
| `MC_HOST` | `5.83.140.250` | IP/хост сервера |
| `MC_PORT` | `25588` | Порт |
| `MC_VERSION` | `auto` | Версия клиента; `auto` — определить по серверу |
| `MC_AUTH` | `offline` | `offline` для offline-mode; `microsoft` для premium |
| `AUTO_JOIN` | `false` | Поднимать всех сохранённых ботов при старте |
| `RECONNECT` | `true` | Авто-переподключение |
| `MAX_RECONNECTS` | `0` | Лимит попыток, `0` = бесконечно |
| `RECONNECT_DELAY_MS` | `5000` | Базовая задержка реконнекта |
| `RECONNECT_MAX_DELAY_MS` | `60000` | Максимальная задержка |
| `JOIN_DELAY_MS` | `1500` | Пауза между запуском ботов |
| `MC_VIEW_DISTANCE` | `tiny` | Дальность прорисовки (меньше CPU/RAM) |
| `MC_PHYSICS` | `false` | Физика бота; если античит против — поставьте `true` |
| `DATA_DIR` | `data` | Где лежит `accounts.json` |
| `ACCOUNTS` | `serphut,serphut1,…` | Начальный список ников (если файла ещё нет) |

По умолчанию команды доступны тем, у кого есть право **«Управление сервером»**.
Хотите только себе — укажите `ADMIN_USER_IDS`, хотите всем — `ALLOW_EVERYONE=true`.

## Проверка без Discord

```powershell
npm run ping                 # пинг сервера: версия, онлайн, игроки
npm run test-join -- serphut1  # зайти одним ботом на 15 секунд и выйти
```

`test-join` — удобно, чтобы проверить ник/вайтлист, не трогая Discord.
Добавьте `-- --reconnect`, чтобы проверить авто-реконнект.

## Работа 24/7 (ПК выключен)

Боту нужна машина, которая включена всегда. Варианты:

### Бесплатно без карты — Render (≈10 минут)

Подробная пошаговая инструкция — в **[RENDER.md](RENDER.md)**. Кратко: Render
даёт бесплатный веб-сервис на 750 часов в месяц — как раз на один сервис
24/7. Минус: диск временный, поэтому список ников задаётся переменной `ACCOUNTS`
и после рестарта возвращается к ней.

1. Загрузите проект в **приватный репозиторий GitHub**. Проще всего распаковать
   `mc-bot-deploy.zip` и перетащить файлы в новый репозиторий через веб-интерфейс
   GitHub (**Add file → Upload files**).
2. Зарегистрируйтесь на <https://render.com> через GitHub — карта не нужна.
3. **New → Blueprint** → выберите репозиторий → **Apply**. Render прочитает
   `render.yaml` и создаст сервис.
4. В сервисе → **Environment** добавьте:
   - `DISCORD_TOKEN` — токен бота;
   - `DISCORD_GUILD_ID` — ID вашего Discord-сервера.

   Сохраните — начнётся redeploy.
5. Дождитесь статуса **Live** и откройте ссылку
   `https://mc-alts-bot-xxxx.onrender.com/` — должно ответить `mc-alts-bot: alive`.
6. **Обязательно** подключите бесплатный пинг, иначе Render усыпит сервис через
   15 минут без запросов и боты отключатся:
   <https://uptimerobot.com> → **Add New Monitor** → HTTP(s) → URL из шага 5 →
   интервал **5 минут**.

Ники по умолчанию — `serphut,serphut1,serphut2,serphut3`. Свои добавьте в
переменную `ACCOUNTS` через запятую и сделайте redeploy. `/add` на Render тоже
работает, но после рестарта список вернётся к `ACCOUNTS`.

Если Render не сможет подключиться к Minecraft-порту (бывает редко) — берите VPS.
На бесплатных 512 МБ RAM комфортно живут 2–3 бота; для четырёх лучше 1 ГБ (VPS).

### VPS — самый надёжный вариант

Минимум **1 CPU / 1 ГБ RAM** (4 бота ≈ 300–500 МБ). Ubuntu 22.04/24.04.

```bash
sudo apt update
sudo apt install -y curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs

# загрузите папку проекта, например:
# scp -r mc-bot user@IP:/opt/mc-bot

cd /opt/mc-bot
npm ci --omit=dev
cp .env.example .env
nano .env        # токен + guild id
npm start        # проверка
```

Автозапуск через systemd — `/etc/systemd/system/mc-bot.service`:

```ini
[Unit]
Description=MC Alts Discord Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=/opt/mc-bot
ExecStart=/usr/bin/node src/index.js
Restart=always
RestartSec=5
EnvironmentFile=/opt/mc-bot/.env

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now mc-bot
journalctl -u mc-bot -f
```

### Docker

```bash
docker compose up -d --build
docker compose logs -f
```

`restart: unless-stopped` уже прописан, `data/` смонтирована наружу.

### Другие бесплатные варианты

- **Oracle Cloud Always Free** (ARM Ampere, 1–4 vCPU / 24 ГБ) — бесплатно
  навсегда, но для регистрации нужна карта (списывают и возвращают ~$1).
  Лучший вариант, если карта есть: полноценный VPS с постоянным диском.
- **Хостинги Discord-ботов** (SillyDev, Discloud и подобные) — 24/7 без карты,
  обычно есть постоянный диск. Это сторонние сервисы: выбирайте тариф с диском
  и смотрите правила (не все любят Minecraft-ботов).
- **Raspberry Pi / старый мини-ПК / Android-телефон (Termux)** — бесплатно, но
  устройство должно быть включено и в сети.
- **Railway / Fly.io** — работают стабильно, но нужна карта и/или оплата.

Важно: у хостинга должен быть исходящий доступ к `5.83.140.250:25588`
(по умолчанию открыт).

## Где хранятся аккаунты

`data/accounts.json` — список ников. При первом запуске создаётся с
`serphut`, `serphut1`, `serphut2`, `serphut3`. Можно редактировать вручную
(бот читает файл при старте) или через `/add` и `/remove`.

Сделайте бэкап файла, если список большой.

## Частые проблемы

| Симптом | Что делать |
| --- | --- |
| `Ты не в вайтлисте` | Ник не добавлен в вайтлист сервера. Добавьте его и повторите `/join`. |
| Бот висит в «подключение» | Обычно ресурспак. В этой версии уже обрабатывается; смотрите логи. |
| `Outdated client` / `Unsupported version` | Поставьте `MC_VERSION=26.1.2` (или актуальную версию сервера). |
| `Invalid session` / `Failed to verify username` | Сервер в `online-mode=true`; нужен premium-вход, а не `offline`. |
| `Server is full` | На сервере 20 слотов, освободите место. |
| Кикает античит | Попробуйте `MC_PHYSICS=true` и `MC_VIEW_DISTANCE=short`. |
| Команды не видны | Проверьте `DISCORD_GUILD_ID`, перепригласите бота со scope `applications.commands`, перезапустите. |
| `Нет доступа` | Нужно право «Управление сервером» или настройте `ADMIN_ROLE_ID` / `ADMIN_USER_IDS`. |
| Токен утёк | Reset Token в Developer Portal и обновите `.env`. |

Логи: консоль, `journalctl -u mc-bot -f` (systemd) или `docker compose logs -f`.

## Пара замечаний

- Один бот ≈ 60–120 МБ RAM. Четыре спокойно живут на 1 ГБ VPS.
- Пока хотя бы один бот онлайн, `/list` показывает полный tab-лист. Без ботов —
  только то, что отдаёт ping (обычно до 12 ников + онлайн).
- Таблист обновляется кнопкой; данные на момент нажатия.
- Используйте ботов только там, где это разрешено правилами сервера. Вайтлист
  проверяется на стороне сервера, бот его не обходит.
